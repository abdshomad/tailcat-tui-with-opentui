Cordis Web Dashboard & REST Architecture

01. Pipe & Raw Stream

Route: /?tab=pipe OpenTUI: Tab 1 (PipeView) API: /api/sessions

HTTP Endpoint & Handlers

GET /?tab=pipe & POST /api/pipe/start

Core Architecture Flow

  • Client Action: Browser user submits Pipe listener form at /?tab=pipe.
  • Cordis Plugin: TailcatWebPlugin parses parameters and invokes TailcatService.spawnPipe().
  • Process Supervision: TailcatService executes tailcat pipe, records PID, and streams session logs.
  • REST Polling: Browser polls /api/sessions to display live tunnel status and token.

Cordis Plugin Dependencies

TailcatWebPlugin · PluginManagerService · TailcatService

OpenTUI & Web Sync

State is unified with OpenTUI Tab 1 (Pipe / Stream). Both interfaces supervise identical background processes via TailcatService.
